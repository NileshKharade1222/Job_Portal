*Job Portal🛠️ Welcome to the Job Portal! This is a Java-based Job Portal web application.
Employers can post job vacancies and manage applications. Job seekers can browse jobs and apply online. *Features🚀: 1)User registration and login system. 2)Applicants can submit our applications. 3)Contact form for user inquiries. 4)Admin panel for managing data.
*Technologies Used💻: 1)Spring Boot: For building the RESTful API. 2)Spring Data JPA: For database interaction. 3)Mysql Database: As an in-memory database for quick setup and testing. 4)Lombok: To reduce boilerplate code for model classes.

*Access the API ▶️: The application runs on https://localhost:8080.
